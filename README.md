# Claude Desktop 汉化补充包（Windows）

在 **[javaht/claude-desktop-zh-cn](https://github.com/javaht/claude-desktop-zh-cn)**（Claude 桌面版中文补丁）基础上做的补充版：把界面翻译补到尽量完整，并加入“外置词典”，补完翻译后重启 Claude 即可生效。

> **原作者汉化包**：<https://github.com/javaht/claude-desktop-zh-cn>
> **下载原作者最新版本**：<https://github.com/javaht/claude-desktop-zh-cn/releases/latest>
>
> 本项目只是补充，汉化的核心机制（安装脚本、网页翻译注入、备份与卸载恢复）都来自原作者，感谢原作者的工作。

## 和原版相比补充了什么

- **词库补全**：前端 32801 条、桌面 758 条全部有中文；原作者已翻译的保持原样优先，本项目只填空白
- **服务器下发的文字**：“回顾”页、用量页、斜杠命令说明、新模型提示等词库里没有的文字
- **带数字 / 日期 / 链接的句子**：如“下午 2:10 重置”“已用 6%”“2026年9月25日”“请阅读我们的安全指南了解详情”
- **顶部菜单和托盘菜单中文化**
- **修正原版的几个问题**：翻译表大小写冲突导致数百条常用词不生效；日期显示成“$2年9月25日”；托盘“Pro 套餐 套餐”
- **外置词典**：翻译另存在 `runtime/`，以后补翻译只需重启 Claude，不用重装

## 使用方法

需要：Windows 版 Claude Desktop、[Node.js](https://nodejs.org/)（生成词典用）。

1. 下载本仓库（Code → Download ZIP）并解压到任意位置。**解压后不要再移动文件夹**（已安装的 Claude 会从这里读取外置词典）。
2. 双击 **`一键汉化.bat`**，在弹出的管理员授权里点“是”。

一键汉化会先检测 Claude 的状态，自动选择做法：

| Claude 当前状态 | 一键汉化会做什么 |
|---|---|
| 还没汉化 | 全盘汉化（官方账号登录模式 + 简体中文），不需要另外下载原作者的包 |
| 已用原作者的汉化包汉化过 | 在原作者的基础上补充，不重装；原作者的译文优先 |
| 已经装过本补充包 | 只更新外置词典 |

**什么时候再点一次**：原作者出了新版本（先按原作者的方式安装，再点）、Claude 自动更新之后、本仓库更新了翻译之后。完成后完全退出 Claude（托盘图标右键 → 退出）再打开。

想用繁体中文、第三方 API 登录模式或卸载恢复，运行 `程序/汉化包/install-windows.bat`，菜单与原作者版本相同。

## 风险提示（请先读）

- 和原作者的“官方账号模式”一样，本工具会修改 Claude 的 `app.asar` 并同步改写 `Claude.exe` 内嵌的校验值，`Claude.exe` 的数字签名会显示为不匹配，**Cowork 沙箱 / 工作区可能无法使用**。
- 汉化只在本机替换界面上显示的文字，不改动发往服务器的请求内容。但修改官方客户端是否符合 Anthropic 的服务条款，请自行判断，风险自负。
- `runtime/` 里的文件会在 Claude 页面中执行，不要放入来源不明的文件，也不要让别人改写这个文件夹。
- 卸载：运行 `程序/汉化包/install-windows.bat`，选择“恢复原样 / 卸载补丁”。

## 文件结构

```
一键汉化.bat      唯一需要点的按钮
runtime/          外置词典（运行后生成）
程序/
  oneclick.ps1    检测状态并选择做法
  supplement.ps1  补充模式（在已有汉化上补充）
  汉化包/         原作者汉化包（MIT 许可，含本项目对安装脚本的修正；原文件保存在 作者原版/）
  工具/           词典、补充翻译和构建工具（见 工具/README.md）
```
